## 🧠 مدل‌های استفاده شده در کد

در این پروژه از رویکرد یادگیری انتقالی (Transfer Learning) و یک استراتژی آموزش دو فازی (ابتدا استخراج ویژگی و سپس تنظیم دقیق یا Fine-tuning) برای دو معماری زیر استفاده شده است:

* **MobileNetV2**: مدلی بسیار سبک با سرعت استنتاج بالا، مناسب برای سیستم‌های بلادرنگ (Real-time).
* **ResNet50**: معماری عمیق‌تر و قدرتمندتر برای استخراج ویژگی‌های پیچیده و دستیابی به بالاترین دقت اعتبارسنجی (بالای ۹۹ درصد).

## 🛠️ راهنمای اجرای محلی (Local Setup)

در صورتی که قصد دارید کدها را روی سیستم شخصی (لوکال) خود اجرا کنید، حتماً به موارد زیر دقت نمایید:

1. پیش‌نیازها و کتابخانه‌های پایتون را از طریق فایل `requirements.txt` موجود در مسیر اصلی پروژه نصب کنید.
2. دیتاسِت اصلی پروژه (State Farm Distracted Driver Detection) را دانلود کنید.
3. مسیر دیتاسِت دانلود شده را در متغیرهای ابتدای کد (مانند `BASE_DIR` و `TRAIN_DIR`) اصلاح کنید تا کد بتواند تصاویر را پیدا کند.
4. به دلیل محدودیت حجم، وزن‌های ذخیره‌شده مدل‌ها (`.h5`) در مخزن گیت‌هاب قرار ندارند و با اجرای کد، فرآیند آموزش شبکه‌ها از نو انجام خواهد شد.
